## Nature of the data

UCI describes the dataset as synthetic data designed to reflect predictive-maintenance data encountered in industry. It is not a log collected from a particular deployed machine or factory.

The file contains 10,000 rows. SensorGuard uses six model features and the binary `Machine failure` target. Identifiers and individual failure-mode target columns are excluded.

## Intended use in this repository

The dataset is used to teach supervised classification, leakage prevention, imbalanced evaluation, probability thresholds, model comparison, and reproducible inference.
